# Feedback questionnaire

1. What were you trying to find?
2. Did the correct file appear? If not, what did you expect?
3. Did the evidence make the result trustworthy?
4. Was any permission or privacy behavior unclear?
5. How long did the first useful result take?
6. Would you prefer this as an end-user search product, API, or both?
7. What workflow would make you return weekly?
8. Would you pay for it, and approximately how much?
