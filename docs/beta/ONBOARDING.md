# Five-minute onboarding

1. Open the private site and sign in with the invited ChatGPT account.
2. Read the read-only access explanation and give consent.
3. Create a workspace.
4. Connect Google Drive and approve the listed read-only permissions.
5. Click **Index now** and wait for the run to complete.
6. Search for an exact phrase you remember.
7. Open **Exact evidence**, **Why this result?**, the trace, and the source.
8. Use **Share feedback** if anything is missing or confusing.
9. Disconnect Drive when finished if you do not want the connection retained.
