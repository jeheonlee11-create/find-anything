# Tutorial video

The production scripts, storyboard, shot list, narration, captions, and optional transition prompts are included. A final MP4 is intentionally not fabricated: deterministic recording requires a browser-capable CI runner and the finished production authentication/OAuth flow. Record the truthful synthetic demo first; add live-account shots only after those systems exist. The target output is `find-anything-product-tour.mp4` at 1920×1080, 60–90 seconds.
