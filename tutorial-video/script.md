# Find Anything product tour script

Find Anything is the permission-aware retrieval control plane for AI agents. This tour uses a clearly labeled synthetic workspace. We open the demo, review 70 fictional Drive records, and run “Find every Google Doc related to air pollution.” Find All returns the complete eligible demo set in pages of 20. We inspect an exact paragraph citation, then coverage: two files await indexing and two failed extraction, so the result is correctly marked incomplete. The retrieval trace explains query parsing, permission decisions, candidate counts, exclusions, and latency. Finally, we export the retrieval record and review the proposed REST and MCP interfaces. Connect real Google Drive only after OAuth, encrypted persistence, and human security review are configured.
