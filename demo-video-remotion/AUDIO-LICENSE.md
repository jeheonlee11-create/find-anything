# Audio source & license record

## Summary
All audio in this video is **100% original and synthesized from scratch** by
`scripts/make-audio.mjs`. No third-party samples, loops, stock libraries, or
commercial/copyrighted music were downloaded or used. There is **no voiceover**
(no human and no AI-generated speech).

## Stems
| Stem | File | Description |
|------|------|-------------|
| Music | `public/audio/music.wav` | Ambient pad bed — an Am–F–C–G progression built from summed sine partials + sub bass, with crossfades and a slow tremolo. |
| Effects | `public/audio/effects.wav` | UI sound design — transition whooshes, confirm chimes, and coverage/feature ticks, all generated from oscillators + exponential envelopes. |

- Format: 44.1 kHz, 16-bit PCM, stereo, 59.0 s.
- Generation is deterministic (no randomness) — re-running `npm run audio`
  reproduces byte-identical stems.

## Levels (measured on the final mux)
- Music peak ≈ −9.0 dBFS · Effects peak ≈ −4.1 dBFS
- Mixed peak (music·0.8 + effects·0.9) ≈ −3.5 dBFS → **no clipping**.

## Regenerating
```bash
npm run audio   # rewrites public/audio/music.wav and effects.wav
```
Adjust the chord table, tempo of events, or gains in `scripts/make-audio.mjs`.
